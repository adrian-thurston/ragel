Def
===

The 'def' is where colm really shines.
A 'def' defines a context-free grammar nonterminal: a type whose values are parse trees.
Each of its productions, between square brackets, is a sequence of tokens and nonterminals, and 'parse' turns input into a tree of that type.
Again one example is much more clearer.

[source,chapel]
.assign.lm
----
include::code/assign.lm[]
----

After the compilation we can pipe some input to it's stdin.

[source,bash]
----
/opt/colm/bin/colm assign.lm
echo -e 'b=3;a=1;\n c=2;' |./assign
----
