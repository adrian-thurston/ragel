== Real FizzBuzz

The fizzbuzz test is often used to check if someone has programming skills.
It is the next logical step to _hello world_.

[source,chapel]
.fizzbuzz.lm
----
include::code/fizzbuzz.lm[]
----

It appears that there is no modulo operator (`%`).
Therefor we'll resort to a function.
Writing a function seems rather straight forward.

Please note:

* that `&&` is working.
* The return type is needed: use `void` for a function that returns nothing.
  A function that ends without a `return` returns 0 if its return type is `int`, `false` if it is `bool`, and `nil` otherwise.

[source,bash]
----
/opt/colm/bin/colm fizzbuzz.lm
./fizzbuzz
----
