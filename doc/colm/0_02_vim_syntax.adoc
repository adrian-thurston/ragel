= Vim syntax

To activate colm syntax highlighting in vim, copy colm's syntax file, `colm.vim`, to vim's syntax directory.
It is at the top of the source tree, and installing colm puts it in the documentation directory, `<prefix>/share/doc/colm-suite`.

 mkdir -p ~/.vim/syntax
 cp /opt/colm/share/doc/colm-suite/colm.vim ~/.vim/syntax/

[source,vim]
.~/.vimrc
----
" Work with colm
au BufRead,BufNewFile *.lm set filetype=colm
----

When we open an `.lm` file, we will see some colors

----
vi src/colm/colm.lm
----
